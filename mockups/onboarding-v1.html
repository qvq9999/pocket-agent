现状的问题
  • 引导只存在于会话空态区：和"你好 / 示例 chip / 版本号"挤在一屏，内容一多就要滚，也不像"一段流程"
  • 每步只有一个按钮，看不到一共几步、做完会怎样；做完前两步没有"已就绪"的反馈
  • 重看会清空当前会话：为了复习说明把正在进行的对话切走（replayOnboard() 里 messages.clear() + 切 sessionId）
  • 「跳过」和「先随便看看」两套语义混在同一张卡里，后果不同却长得一样
方案
  • 新增 Screen.Onboard 全屏页：盖在会话页之上，有 `‹` 返回；首启自动进入，设置里可重看
  • 顶部 3 段进度条，右上角"第 N 步 / 共 3 步"
  • 每页 = 大标题 + 一句说明 + 三步状态示意（✓ / 待完成）+ 主按钮做那件事
  • 底部固定：跳过 ｜ 主按钮；最后一步变 开始使用
  • 状态仍按现状推导：加完模型回来这一步自动打勾；重看则固定从第 1 步翻，但按钮变成「下一步」
  • 去掉清会话的副作用：页面独立后不需要清空消息，直接切页
  • 「先随便看看」并入右上角 ✕（临时关闭、不写状态）；底部只留「跳过」（写 dismissedAt）
内容也要改的三处
  • 第 1 步补一句"请求直接从手机发到厂商，中途不经过我们"——现在只说了"只存本机"，没说"去哪了"
  • 第 3 步的示例要把新能力摆出来（做 PPT / 做 Word），现在的示例只有"改名 / 总结笔记"
  • 收尾给一句边界：能做什么、不能做什么（不做图片/图表、删除需要确认），比现在"也能直接把文件发进来"更有用
